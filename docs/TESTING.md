# Tower Smash 3D — tester script

About 15 minutes. Use your own phone, and do it in one sitting if you can.

Send feedback from **menu (top left) › Send feedback** after any step that surprises, confuses or breaks.

| # | Do this | Look for |
|---|---|---|
| 1 | Open the link fresh (or use a private tab) | Does a loading screen appear within a second? |
| 2 | Tap Play, go through the three intro cards, enter a name | Is it clear what the game is? |
| 3 | Finish the Training Yard (smash part, then build part) | Did you ever get stuck or need to ask what to do? |
| 4 | From Home, tap Continue and play three campaign levels | Are stars and coins clear? Any level impossible? |
| 5 | Free play: build a wall with Line or Walls, then Fuse › Weld it | Do the tools make sense without reading Help? |
| 6 | Switch to Smash and try five weapons from different categories | Anything ugly, slow or confusing? |
| 7 | Home › Duels: build a fortress and send it to someone | Did the link work for them? |
| 8 | Build › + Add › Create: describe a building to the AI Architect | Did it build something sensible? |
| 9 | Menu › Settings: try Graphics Auto/High/Light | Does High run smoothly on your phone? |
| 10 | Send one piece of feedback, even "all good" | Did sending work? |

Tell us your phone model and browser if the report doesn't include it.
